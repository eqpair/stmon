# stmon v2 — 보통주 숏 / 우선주 롱

기존 stmon 서비스 안에서 돌아갑니다. 3분 주기 모니터링·웹 데이터·GitHub 푸시는 그대로 두고, 아래가 바뀝니다.

- 화면과 알림의 `sz`가 v2 Z로 바뀜(120일, ln(보통주/우선주)). IN/OUT/CHK는 Z≥2.0 / Z≤0.4 / 그 사이.
- **15:15** 매매 신호(ENTER / EXIT_TARGET / EXIT_STOP / HOLD)를 텔레그램으로 발송하고 `data/v2_signals.json` 저장
- **15:45** 확정 종가로 `data/history` 갱신
- 장중 Z≥2.0 알림은 참고용으로 유지(문구 변경)
- 텔레그램 `/v2`: 지금 바로 신호 계산
- 텔레그램 토큰은 `config_secrets.py`(git 제외)로 이동

## 규칙 (config.py `V2_PARAMS`, 정의는 modules/strategy.py)

| 항목 | 값 |
|---|---|
| 스프레드 | ln(보통주/우선주), 직전 120거래일 평균·표준편차로 Z |
| 진입 | Z ≥ 2.0 이고 기대수익 (Z−0.4)×σ ≥ 3% |
| 청산 | Z ≤ 0.4 |
| 손절 | 페어 손익 ≤ −15% |
| 재진입 | 손절 뒤 Z < 1.0이 된 다음에만 (pair-trades.json의 실제 손절도 반영) |
| 진입 금지 | 우선주 60일 −50% 이하 / 최근 20일 중 하루 ±31% 초과 변동 / 공매도 금지 기간(`V2_BLACKOUT`) |
| 동시 보유 | 10쌍(`V2_SLOTS`), 빈 칸은 기대수익 큰 순 |

## 검증 (1997~2026-10, 10슬롯, 편도 30bp + 스왑 연 4%, 공매도 금지기간 진입 없음, 배당 제외)

| | 현행 규칙 | v2 |
|---|---|---|
| 같은 날 종가 판단·체결: Sharpe / 연수익 / MDD | 0.97 / 19.2% / −60.7% | 1.78 / 28.5% / −25.7% |
| 전일 판단 → 당일 체결(보수적) | 0.81 / 15.7% / −60.6% | 1.00 / 15.0% / −39.2% |
| 2021년 이후 Sharpe (같은 날 / 보수적) | 0.23 / 0.27 | 0.71 / 0.38 |

- 레그당 명목 = 자본/10, 10칸이 차면 총 명목 = 자본의 2배.
- 실제(15:15 판단 → 동시호가 체결)는 두 행 사이. **기대치는 보수적 행 기준으로**.
- 쌍별 기준: 훈련(~2012)에서 쌍마다 고른 진입·청산 기준이 검증 구간에서 일관되게 낫지 않아 공통 기준 사용.
  필요하면 `V2_PAIR_PARAMS = {'005930': Params(z_in=2.5)}` 처럼 예외 지정 가능(백테스트·신호 모두 반영).

## 명령

```bash
python3 backtest.py                 # 검증 재현(같은 날 체결)
python3 backtest.py --lag 1         # 보수적 체결
python3 backtest.py --z_in 2.25 --stop 0.2   # 파라미터 바꿔보기
python3 -m modules.v2 --no-live     # 마지막 종가 기준 신호
python3 -m modules.v2 --update      # 이력 갱신 후 현재가 기준 신호
```

## 쌍 추가·삭제
- 삭제(상장폐지 등): `config.py` TICK_PAIRS에서 줄 삭제 + `data/history/{보통주}_{우선주}.csv` 삭제
  (`modules/utils.py`의 종목명 매핑은 남아 있어도 무방)
- 추가: TICK_PAIRS에 추가 + `data/history/{보통주}_{우선주}.csv`(date,C,P 수정주가) 생성.
  이력이 750일 미만이면 신호는 보이지만 신규 진입 후보에서 제외됨.

## 운용
1. 15:15 텔레그램 신호 확인 → 동시호가 체결
2. 체결 후 `data/pair-trades.json` 기록(기존 방식). 손절로 청산했으면 `"exit_reason": "STOP"` 추가 권장
3. 손절은 반드시 지킬 것. 신호와 다르게 매매하면 검증 성과와 달라짐
4. `data/v2_signal_log.csv`의 신호가격과 실제 체결가를 비교해 실제 비용 확인
