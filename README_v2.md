# stmon — 보통주 숏 / 우선주 롱 매매 프로그램

주문은 직접 하고, 나머지(감시·주문표·수량·기록·리스크·성과)는 프로그램이 합니다.

## 하루 흐름 (평일)

| 시각 | 하는 일 |
|---|---|
| 08:30~16:30, 3분마다 | 85쌍 현재가 일괄 조회 → Z·보유 손익 계산 → 웹 갱신 → 장중 알림 |
| 장중 수시 | 🚨 손절선 도달 / ⚠️ 손절선 접근(−10%) / 👀 진입 조건 근접 (종목·종류별 하루 1번) |
| **15:15** | 📋 **주문표**: 청산·진입 종목, 수량(자본 설정 시), 손절까지 남은 폭 |
| 동시호가 | 직접 주문 → 텔레그램 `/in`, `/out`으로 체결 기록 |
| **15:45** | 확정 종가로 이력 갱신 → 재진입 상태 재계산 → 일별 손익 기록 → (금요일) 주간 성과 리포트 |

## 텔레그램 명령

```
/p   보유 현황 (손익, 손절까지 남은 폭, 규칙상 청산 여부)
/w   관심 종목 (Z 상위, 재진입대기·이력부족 표시)
/o   지금 가격 기준 주문표 미리보기 (기록 안 남음)
/r   성과 리포트 (누적손익, 승률, 슬리피지, 규칙 준수)
/in  005300 300@123400 470@98000 [2026-11-02]     진입 체결 기록 (보통주 숏 수량@가격, 우선주 롱 수량@가격)
/out 005300 120500 99100 [STOP] [2026-11-03]       청산 체결 기록 (손절이면 STOP — 재진입 금지에 반영)
```
명령은 `CHAT_ID` 방(또는 `ALLOWED_USER_IDS` 사용자)에서만 받습니다.
`/in` 기록에는 `config.py`의 기본 스왑 금리(`V2_BENCH_RATE`, 스프레드)가 들어가니 실제 계약 금리로 맞춰 두세요.
`pair-trades.json`을 직접 고쳐도 됩니다(형식 동일).

## 규칙 (core/strategy.py — 백테스트와 공용)

| 항목 | 값 |
|---|---|
| 스프레드 | ln(보통주/우선주), 직전 120거래일 평균·표준편차로 Z |
| 진입 | Z ≥ 2.0 이고 기대수익 (Z−0.4)×σ ≥ 3% |
| 청산 | Z ≤ 0.4 |
| 손절 | 전략 손익 ≤ −15% (종가 기준, 15:15 주문표에서 확정) |
| 재진입 | 손절 뒤 Z < 1.0이 된 다음에만 (백테스트 재생 + 장부의 실제 손절 반영) |
| 진입 금지 | 우선주 60일 −50% / 최근 20일 하루 ±31% 초과 / 공매도 금지 기간 / 이력 750일 미만 |
| 동시 보유 | 10쌍. 빈 칸은 기대수익 큰 순 |

## 자금·리스크 (config.py)

| 설정 | 기본 | 의미 |
|---|---|---|
| `V2_CAPITAL` | None | 총 운용자금. **넣어야 주문표에 수량이 나옴** |
| `V2_SLOTS` | 10 | 레그당 금액 = 자본/10 (10칸이 다 차면 총 명목 = 자본의 2배) |
| `V2_GROSS_LIMIT` | 2.0 | 총 명목(숏+롱)/자본 상한 |
| `V2_LIQ_FRAC` | 0.10 | 레그 금액 ≤ 20일 평균 거래대금×10%. 한도가 레그 금액의 30% 미만이면 진입 제외 |
| `V2_STOP_WARN` | 0.10 | 장중 손절선 접근 알림 기준 |

처음 1~2개월은 `V2_CAPITAL`을 실제의 절반으로 넣어 시작하고, `/r` 리포트의 슬리피지(가정 30bp)를 확인하는 걸 권합니다.

## 검증 (1997~2026-10, 10슬롯, 편도 30bp + 스왑 연 4%, 공매도 금지기간 진입 없음, 배당 제외)

| | 이전 규칙 | 현재 규칙 |
|---|---|---|
| 같은 날 종가 판단·체결: Sharpe / 연수익 / MDD | 0.97 / 19.2% / −60.7% | 1.78 / 28.5% / −25.7% |
| 전일 판단 → 당일 체결(보수적) | 0.81 / 15.7% / −60.6% | 1.00 / 15.0% / −39.2% |
| 2021년 이후 Sharpe (같은 날 / 보수적) | 0.23 / 0.27 | 0.71 / 0.38 |

실제(15:15 판단 → 동시호가)는 두 행 사이. 기대치는 보수적 행 기준으로.
쌍별 기준은 검증 구간에서 일관되게 낫지 않아 공통 기준 사용(`V2_PAIR_PARAMS`로 예외 지정 가능).
